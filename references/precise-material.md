# 精准素材筛选与口令清单（阶段 A）

## 唯一可靠判据：官方投放编号

红果官方投放素材的描述形如：

```
1118-LYT-不用逐集解锁漫剧 #红果漫剧 #免费漫剧 #仿真人剧 #你的漫剧搭子
1115-ZQW-别再解锁追漫剧了 #红果漫剧 #免费漫剧 #你的漫剧搭子
```

结构 = `日期(MMDD) - 渠道码(2-6位大写) - 话术` + 话题标签。
- 正则：`\b\d{4}-[A-Z]{2,6}-`
- 常见渠道码：LYT / HWB / LHX / DZF / LLK / ZXW / ZQW / ZYY / CTT / ZXY 等

**这是区分"官方投放素材"和"蹭话题普通分享"的唯一可靠信号。**

### 反面教训（用户明确纠偏过）
第一版清单把"红果/短剧/免费/全集"当泛词正向匹配，结果前 4 条是蹭话题的高赞追剧分享
（凤美民、似风等）。用户说："前面1234这四个都不是我想要的，第五个才是我想精准抓取的"。
第五个就是带 `1118-LYT-...` 编号的官方素材。**点赞量再高，没编号就不是要的东西。**

## 筛选口径（三条同时满足）

1. `desc` 含官方投放编号（正则如上）
2. 点赞 ≥ 100
3. 编号月份 ≥ 11（剔除 10 月及更早的旧投放）

参考规模（某次全量 1042 条）：带编号 79 条 → 赞≥100 共 22 条 → 11 月投放 16 条。

脚本：`scripts/筛选精准_投放编号.py` → `filtered_precise.json`

## 关键词抓取覆盖两条线

- 红果**短剧**（真人剧）
- 红果**漫剧**（动态漫/仿真人剧）— 起量素材主要集中在这条线，只搜短剧会漏掉大部分爆款

## 补链与校验

`scripts/补链_precise.py`：
- 复用已有短链，其余用 `hongguo-douyin-material` 的 `dy_shortlink.py` 逻辑补
- 可见浏览器 + 登录态；两次点击：分享图标 → 面板里的「复制链接」（`web_shorten` 接口才会发出）
- **视频 ID 级校验**：跳转后的 ID 必须与目标一致；降级短码要剔除
- 风控：部分短链会补链失败，失败的直接剔除，不要硬凑

## 清单三件套

`scripts/生成清单_precise.py` →
- `红果短剧推广口令清单_精准.html`：每条卡片顶部蓝框显示官方投放编号，含「复制口令」「打开视频」「复制全部」
- `红果短剧推广口令_精准.csv`：编号/话术、口令全文、账号、赞评转、短链、视频ID
- `红果短剧推广口令_精准.txt`：纯口令逐行版

### HTML JS 坑
复制按钮必须用 `class=copybtn` + `data-i` + 事件绑定，配 `execCommand` 兜底。
**不要**把 JSON 内联进 `onclick`（中文/引号转义会破坏 JS，导致整页复制功能失效）。
本次已两次踩坑并修复，生成后建议用浏览器实测一遍复制按钮。
