# 文案库与画面迭代库（阶段 B）

## 文案库：入"视频里的实际口播"，不是标题

用户强调过两次：文案库要的是**视频里实际念的口播文案**，不是 desc 标题、不是提词稿。

### 口播 ≠ 标题（实例）
某条标题是"不用逐集解锁漫剧"，但视频里实际念的是：
"你也在追AI短剧？为什么你的是青色图标？青绿色的红果漫剧是新推出的…"
这就是必须做音轨转写的原因。

### 构建流程
1. 下载候选视频：`scripts/grab_precise_audio.py`
2. 对 mp4 调宿主 `AudioTranscribe` 工具（不要自己接 ASR 接口）
   - 转写拿到的是带时间轴的完整对话/旁白
   - 对话版要把两段说话人台词合并成完整段落
   - 口播主要有 4 种结构：口语版旁白 / 对话版(两人问答) / 书面版 / 提问钩子版
3. 把转写正文写入 `文案库_新增.json`：
   ```json
   {"text":"<实际口播>","cat":"口播·原版","digg":<赞>,"author":"<账号>",
    "date":"YYYY-MM-DD","vid":"<视频ID>","source":"口播原版 新转写(<风格>) · <投放编号>",
    "note":"..."}
   ```
4. `scripts/build_copy_library.py` + `scripts/build_copy_library_html.py` 重建

### 三个关键坑
1. **`clean_desc` 剥离编号**：`build_copy_library.py` 的抓取分支用正则 `\d{4}-[A-Z]{2,4}-`
   把官方投放编号洗掉。想保留编号（投放·精准素材）必须写入 `文案库_新增.json` 的 `added` 分支
   ——它不经过 clean_desc，text 原样保留。别混用两条分支。
2. **HTML 配色**：新增分类必须在 `build_copy_library_html.py` 的 `CAT_COLORS` 加颜色，
   否则新分类无色。例：`'投放·精准':'#e11d48'`、`'口播·原版':'#6d28d9'`。
3. **去重**：文案库按 text 精确去重。转写内容高度相似但不完全相同的会各自独立入库；
   一字不差的会被跳过（正常）。

### 本次沉淀的分类
- `口播·原版` — 视频音轨 ASR 转写的真实口播（含口语版/对话版/书面版/提问钩子版）
- `口播·成片` — 已用于成片的实际口播
- `投放·精准` — 带完整官方投放编号的话术（编号+话题标签全保留）
- 其他历史分类按既有配色

## 画面迭代库：Seedream 5.5 + 固定场景换主体

### 迭代铁律
一次只换一个变量。**固定场景/光位/构图/道具/机位/画风，只换动物主体。**
主体和场景都换就不是迭代，是重做，数据无法归因。

### 从视频抽原帧
```
ffmpeg -v error -y -i in.mp4 -vf "fps=1/3" frames/f_%02d.jpg
```
实测推广素材是 **1280×720 横屏**（不是竖屏）。抽帧后用 ViewImage 看清主体/场景/构图再写 prompt。

### 生图
`scripts/gen_image.py`：
- 模型默认 **Seedream 5.5**（`HGP_IMG_MODEL` 覆盖）
- 多 tag 批量：`--tag X --subject "..." --tag Y --subject "..." --scene "<固定场景描述>" --ratio 16:9`
- 场景描述把"除主体外的一切"写死：背景、光位、道具、机位、主体占比、留白给字幕、"不要文字不要水印"
- 出图居中裁 16:9：`crop=1536:864:0:80,scale=1280:720`
- 自动入 `画面迭代库.json` / HTML，记录到 `画面迭代库_生成记录.json`

### 水印铁律（本次反复踩坑）
网关返回的 `source_watermarked` 标记**不可信**——Seedream 5.5 默认带"豆包AI生成"水印，
但网关常误标 `false`。因此：
- 批量生图后**无条件 delogo 擦除**右下角（调用 `gen_image.remove_watermark()`）
- 同步更新生成记录的 `watermark_removed=true` / `source_watermarked=true`
- 重建缩略图 + `scripts/build_visual_library.py`
- 擦完抽查一张确认无痕、主体无破损
